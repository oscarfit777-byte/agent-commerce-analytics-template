# OscarFit Commercial Platform 🦅

Plataforma de alta conversión comercial y preventa para **OscarFit**. Desarrollada con arquitectura moderna: **Vite**, **React**, **Tailwind CSS**, y cliente oficial de **Supabase**.

---

## 🎨 Características Visuales y de Arquitectura
- **Dark Mode Absoluto**: Fondo negro `#000000`, tarjetas en tonos `#0A0A0A`, textos blancos y acentos en verde neón `#00FF66`.
- **Identidad del Águila**: Logotipo vectorial deportivo, resplandores neón y tipografía atlética.
- **Catálogo Oficial (Única Fuente de Verdad)**:
  1. *App Móvil OscarFit*: $47 USD (Pago único / Acceso digital).
  2. *Asesoría Online 1 a 1*: $65 USD / mes (Plazas limitadas).
  3. *Entrenamiento Presencial VIP*: $120 USD / mes.
  4. *Guías PDF / El Código 714*: $19.99 USD.
- **Pipeline de Órdenes Seguras**:
  - Estado: `pendiente_verificacion`.
  - Método: Transferencia Bancaria Directa.
  - Generador de código único: `#OF-XXXXX`.
  - Integración nativa con WhatsApp pre-rellenado para envío de comprobantes.
  - Sincronización con tabla `orders` en Supabase con respaldo local resiliente.

## 🚀 Puesta en Marcha Local

```bash
# 1. Entrar en la carpeta del proyecto
cd oscarfit-app

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
```

El servidor estará disponible en `http://localhost:5173`.

## 🗄️ Conexión con Supabase

1. Crea un proyecto en [supabase.com](https://supabase.com).
2. Ve a **SQL Editor** y ejecuta:

```sql
create table if not exists public.orders (
  id bigint generated by default as identity primary key,
  order_code text not null unique,
  product_id text not null,
  product_name text not null,
  amount_usd numeric(10,2) not null,
  billing_type text not null,
  customer_name text not null,
  customer_email text not null,
  customer_phone text not null,
  payment_method text default 'transferencia_bancaria',
  status text default 'pendiente_verificacion',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table public.orders enable row level security;

create policy "Permitir insercion publica de pedidos" 
on public.orders for insert with check (true);

create policy "Permitir lectura para administradores" 
on public.orders for select using (true);
```

3. Actualiza tu archivo `.env`:
```env
VITE_SUPABASE_URL=https://tu-proyecto.supabase.co
VITE_SUPABASE_ANON_KEY=tu-anon-key-aqui
VITE_WHATSAPP_PHONE=573001234567
```
